# 2026-10-24 持仓读取实验

本轮实际执行了前台窗口确认、持仓表格区域右击及取消、单击持仓记录和 Ctrl+C。没有发送买卖、撤单快捷键，没有提交委托。

右击空白区域与持仓记录均未读到可用菜单。复制前检查唯一资金持仓页、表格命中、修饰键未按下、键盘焦点位于表格；Ctrl+C 后剪贴板未变化，没有读取原有剪贴板内容。

截图确认表格内确有数据。第一次全窗口原始 OCR 有代码拆分、数量漏读，未被当成可靠持仓。改为 Windows System.Drawing 裁切表格、2 倍放大及绿色通道灰度增强后，Windows 自带简体中文 OCR 产生可解析的代码、名称、持仓数量和可用数量。

解析器使用精确表头及相邻列边界，拒绝缺失／重复表头、不可读代码、数量非数字、可用数量大于总量、重复代码。无可读行视为无法判断，不视为空仓。候选明确不可执行且不是完整组合，不自动修正 OCR 文字。7 项合成数据测试通过。

原始截图、OCR 和候选包含账户数据，仅保存在私有 diagnostics／.local。未将真实金融数据写入测试或普通报告。后续仍需多行、滚动和人工核对验证；委托成交读取、策略及真实下单尚未实现。
